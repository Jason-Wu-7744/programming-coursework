Maintained by Jason. These files came from the student source directory's top level; their exact assignment association is unknown. They are practice rather than claims of original research.

| Script | Observed role |
| --- | --- |
| [sales_origin_pie_charts.py](sales_origin_pie_charts.py) | Pie charts from embedded percentages; no external input. |
| [akshare_index_constituents.py](akshare_index_constituents.py) | Request index constituents using akshare and write a local CSV. |
| [compound_growth_turtle.py](compound_growth_turtle.py) | Interactive compound-growth input and Turtle plotting. |

Install requirements from this course directory, use supplementary/ as the working directory and run one chosen script. The akshare script makes a network request when run; its current API, availability and terms were not checked. Turtle requires a GUI and input. Embedded pie-chart percentages are not asserted to be sourced market facts. All scripts received syntax-only compilation; none was executed.
