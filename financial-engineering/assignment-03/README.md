# Assignment 03 · BSM Option Price Sensitivity

[English](README.md) | [中文](README.zh-CN.md)

Calculate European call and put prices with the Black–Scholes–Merton model.

- Vary spot price and strike price.
- Vary volatility, the risk-free rate and time to expiry.
- Compare call and put responses while holding the remaining parameters fixed.

The script produces five price-sensitivity charts.
