# Assignment 02 · Treasury Futures Duration Hedging

[English](README.md) | [中文](README.zh-CN.md)

Use bond cash flows and duration to calculate a Treasury futures hedge.

- Calculate accrued interest, full prices and coupon cash flows.
- Solve yields to maturity by bisection and calculate bond and portfolio durations.
- Use the cheapest-to-deliver bond's duration to estimate the short futures quantity.

Results include bond yields, durations, portfolio value and the hedge position.
