# Assignment 01 · Equity Index Futures Hedging

[English](README.md) | [中文](README.zh-CN.md)

Compare an equally weighted stock basket with four index futures and calculate a hedge position.

- Compute stock, portfolio and futures log returns.
- Compare IF, IH, IC and IM with OLS regressions and R squared.
- Calculate the hedge ratio and short futures quantity.

Results include return comparisons, regression summaries and a fitted scatterplot.
