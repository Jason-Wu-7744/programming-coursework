# Assignment 04 · Implied Volatility Smiles

[English](README.md) | [中文](README.zh-CN.md)

Recover implied volatility from option prices by numerically inverting the BSM formula.

- Read paired call and put prices across strikes.
- Solve for volatility for the May, June, September and December expiries.
- Plot call and put implied volatility against strike price.

The script produces four expiry-specific smile charts.
