# 课程论文：AI 相关股票与资产定价

[English](README.md) | 中文

探索性课程研究，结合 CAPM、Fama–French 回归、联合检验、产业链分组和随机森林重要性。课程要求选题结合金融计算与机器学习；这里保留提交代码，不作经过同行评审的研究主张。

## 文件与运行

- data_v1.py：合并因子数据、回归、联合检验和探索性随机森林。
- pie_ML.py：可视化；部分图可能使用手工录入的历史结果，并非自动重算的估计。

在本目录运行，先取得读取语句要求的 data_CN_v4.csv、因子工作簿和衍生文件，逐项检查字段选择。原数据和带身份的提交文档不分发。

## 解读限制

拟合与重要性只表示探索性关联。随机森林在全样本拟合，不构成样本外预测表现或因果证据；变量重要性也不能单独证明估值泡沫。公开定量结论前应核对原报告、修正表和重算结果。已知 AI 辅助版本及外部来源应明确标识，不提出新的绩效、因果或投资主张。
