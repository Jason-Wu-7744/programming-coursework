# Course paper: AI-related stocks and asset pricing

[简体中文](README.zh-CN.md)

An exploratory study combining factor regressions, industry-chain grouping and random-forest feature importance.

- [pie_ML.py](pie_ML.py) — Feature-importance and industry-chain visualizations using stored study results.
